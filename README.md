# RiVa Smart demo teardown (private study copy)

Local, offline copy of two interactive demos from rivasmart.com, with analysis and a few usability additions.

- `home/index.html` — full Ishara Smart Living landing page; its "Try it yourself" house has the gate, walk in / walk out, camera, music, motion and voice extras
- `home/demo.html` — the house demo on its own
- `home/` — homepage "Try it yourself" demo (day/night, curtains, lights, lock, camera, speaker, motion sensor, voice) + extras
- `tour/` — walkable 3D Matter home (three.js 0.149, vendored) with double-click doors/curtains/TV and click-to-walk
- `ANALYSIS.md` — full breakdown of both
- `raw/` — original downloaded HTML/CSS for reference

Run: `python3 serve.py` in this folder, open http://localhost:8765 (use Chrome for voice).

Original code, images and logos belong to RiVa Smart; 3D model "Confortable appartment" by SofianeLasri (CC-BY). Private study only — do not republish.
